# عقد ميزة توثيق الدرفة الخاصة

## النتيجة المطلوبة

يستطيع مدخل البيانات توثيق شكل درفة خاصة خلال أقل من دقيقتين بطريقة يفهمها العميل والمصمم، من دون معرفة CAD ومن دون إنشاء هندسة تصنيع بالخطأ.

## المستخدمون

- **مدخل البيانات:** ينشئ ويعدل التوثيق عندما تسمح حالة الطلب وصلاحياته.
- **المصمم:** يقرأ صورة المرجع والقياسات والملاحظات ويستخدمها لبناء ملف التصنيع في CAD خارجي.
- **المراجع/الطباعة:** يعرض التوثيق دون أسعار أو بيانات داخلية.

## المسارات الأساسية

1. يفتح المستخدم الدرفة الخاصة من الطلب.
2. يختار نقطة بداية واحدة: رفع صورة، مسحها من السكانر، التقاطها بالكاميرا، شكل جاهز، أو قلم ذكي.
3. يضيف القياسات والملاحظات، ويعاين ملخص التوثيق.
4. يحفظ التوثيق؛ تظهر حالة «موثقة» في الطلب.
5. يظهر نفس الملخص في الطباعة ومساحة المصمم.
6. ينشئ المصمم هندسة التصنيع خارج هذا المحرر ويحمّلها عبر مسار DXF/الخطة القائم.

## نموذج البيانات

```json
{
  "schema": "almdina.special-shape-documentation",
  "version": 1,
  "canvas": { "widthMm": 800, "heightMm": 2100 },
  "reference": {
    "fileUrl": "/private/files/example.jpg",
    "rotationDeg": 0,
    "opacity": 0.72,
    "locked": true
  },
  "elements": [],
  "notes": "ملاحظات المصمم",
  "source": "image",
  "templateId": null
}
```

أنواع `elements` المسموحة:

- `stroke`: ضربة قلم مبسطة مع نقاط بالميليمتر.
- `line`: خط توضيحي.
- `rect`: مستطيل أو فتحة.
- `ellipse`: دائرة أو قطع ناقص.
- `arrow`: سهم اتجاه.
- `dimension`: قياس بين نقطتين مع قيمة وملصق.
- `text`: ملاحظة قصيرة في موضع على اللوحة.

هذه العناصر توضيحية ولا تُحوّل إلى `special_shape_geometry_json`.

## Acceptance Criteria

### AC-01 — نقطة دخول واضحة

عند فتح درفة `Special` يظهر محرر «توثيق الدرفة الخاصة» ببيانات الطلب ورقم الدرفة ومقاسها. لا تظهر أدوات CAD أو DXF أو القيود الهندسية في هذا السطح.

تظهر حالة تحميل مرئية فور إنشاء الصفحة، ولا تبقى الشاشة بيضاء أثناء تنزيل الأصول. تُحمّل ملفات الواجهة بالتوازي بدل سلسلة طلبات متتابعة، وتحل الوحدات اعتمادياتها بعد اكتمال دفعة التحميل، ويستهدف UAT وصول الواجهة إلى حالة تفاعلية خلال 4 ثوانٍ على شبكة الاختبار المرجعية.

### AC-02 — صورة مرجعية

تظهر ثلاثة خيارات مستقلة وواضحة: «رفع صورة»، «مسح بالسكانر»، و«التقاط بالكاميرا». يستخدم خيار السكانر تطبيق Almdina المحلي المثبّت على Windows لفتح واجهة WIA القياسية ثم يمرر الصورة إلى خدمة الرفع الخاصة نفسها. يثبّت مسؤول الأجهزة التطبيق مرة واحدة لكل مستخدم؛ يبدأ تلقائيًا مع تسجيل الدخول ويعمل في شريط النظام من دون PowerShell أو نافذة أوامر أو صلاحية مدير. عند غيابه تعرض الواجهة رابط تنزيل المثبت وإجراءً واضحًا لفتحه من قائمة ابدأ. الإلغاء لا يغيّر الوثيقة، ورفض الموقع أو فشل الجهاز يظهر برسالة عربية قابلة للتنفيذ. تُرفض الأنواع والأحجام غير المسموحة برسالة واضحة، ويمكن تدوير الصورة وتغيير شفافيتها وقفلها وحذفها.

### AC-03 — الخصوصية والنطاق

الصورة تحفظ كملف خاص مرتبط بالطلب والدرفة. لا يستطيع مستخدم يملك رابط ملف فقط قراءته أو استبداله أو حذفه دون صلاحية ونطاق الوثيقة.

### AC-04 — الملاحظات والقياسات

يستطيع المستخدم إضافة ملاحظة عامة، نصوص على اللوحة، وقياسات توضيحية بوحدتي mm وcm. تظهر القيم في المعاينة والطباعة كما أُدخلت.

### AC-05 — الأشكال الجاهزة

تتوفر على الأقل: زاوية مقصوصة، قوس علوي، قوس جانبي، شبه منحرف، فتحة داخلية، وحافة مائلة. يطبق الشكل على مقاس الدرفة ويمكن تعديل مقابضه وإضافة القياسات إليه.

### AC-06 — القلم الذكي

ينظف القلم الضوضاء مع المحافظة على المنعطفات المقصودة. يطبق التثبيت قرب الأفقي/العمودي/45° على الضربة المستقيمة ككل، ولا يثبت أضلاع المنحنى واحدًا واحدًا. يحتفظ القوس بعدد نقاط كافٍ لعرض ناعم، ويستفيد من عينات القلم/المؤشر المجمعة، ويقترح إغلاق الأطراف القريبة بدل فرضه. يمكن التراجع عن آخر عملية وإعادة تنفيذها.

مساحة الرسم حرة ولا يظهر مقاس الدرفة كصفحة تقيد موضع العناصر أو تغيير حجمها. تبقى وحدات العناصر بالـmm ويبقى مقاس الدرفة في عقد الوثيقة وبيانات الطلب. يبدأ عرض 40 cm عند Zoom مريح 100%، ويدعم التكبير حول المؤشر والتحريك وملاءمة كامل الرسم. تلائم الطباعة جميع العناصر حتى إن امتدت قبل أصل الدرفة أو بعد أبعادها الاسمية.

### AC-07 — حفظ مستقل

حفظ التوثيق يحدث `special_shape_drawing_json` وحالة التوثيق وبيانات آخر تعديل فقط. لا يكتب `special_shape_geometry_json`، ولا يغير `plan_needs_recalculation` أو hashes الخطة، ولا يلغي سعرًا خاصًا تمت مراجعته. إعادة التسعير مرتبطة بتغير نوع الدرفة أو عرضها أو طولها أو كميتها وفق سياسة التسعير الحالية.

### AC-08 — منع الحفظ الفارغ

لا يعتبر السجل موثقًا إلا إذا احتوى على صورة مرجعية أو عنصر مرسوم واحد على الأقل، ومعه ملاحظة أو قياس عندما لا يكون الشكل واضحًا. توضح الواجهة النقص قبل الإرسال.

### AC-09 — العرض والطباعة

يعرض الطلب حالة التوثيق ويفتح معاينة للقراءة فقط. تعرض الطباعة صورة المرجع والعناصر والقياسات والملاحظات ورقم الدرفة ومقاسها، من دون تكلفة أو صلاحيات تعديل.

### AC-10 — تسليم المصمم

تحتوي مساحة المصمم على نفس المعاينة ورابط تنزيل الصورة الأصلية عند السماح، مع نص صريح: «هذا توثيق لطلب العميل وليس ملف تصنيع».

### AC-11 — الحالة غير المحفوظة

تظهر حالة محفوظ/غير محفوظ/جار الحفظ/فشل الحفظ. عند الرجوع مع تعديلات غير محفوظة يطلب النظام تأكيدًا. لا تستطيع استجابة قديمة استبدال درفة أحدث.

### AC-12 — الأجهزة والإتاحة

تعمل الأدوات الأساسية بالماوس واللمس والقلم ولوحة المفاتيح. تستخدم اختصارات الأدوات `V/P/L/R/O/D/T` والنسخ واللصق والتراجع والإعادة `Ctrl+C/V/Z/Y` موضع المفتاح الفيزيائي، لذلك تعمل مع تخطيط لوحة مفاتيح عربي أو إنكليزي. الواجهة عربية RTL، أهداف اللمس لا تقل عن 40px، ويوجد focus واضح وتسميات وصول للأزرار.

### AC-13 — التحويل والتنظيف

بعد نجاح اختبارات الوحدة والعقود وUAT، تصبح الصفحة الجديدة نقطة الدخول الوحيدة. تُحذف ملفات وأصول واختبارات V3/V4 والمحررات المضمّنة القديمة، وتفشل بوابة CI إذا ظهر مرجع runtime إليها.

## خارج النطاق

- إنشاء أو تعديل أو اعتماد DXF.
- حساب polygon صالح للتصنيع من الرسم التوضيحي.
- تغيير optimizer أو cutting plan أو margins أو تكاليف الألواح.
- استبدال برنامج CAD الخارجي.
- استدعاء TWAIN/WIA مباشرة من المتصفح أو حفظ بيانات السكانر داخل JSON. التكامل المعتمد هو تطبيق Almdina المحلي المثبّت، المقيد بـloopback وOrigin، ثم خدمة رفع الصورة الخاصة القائمة.

## تعريف الاكتمال

تكتمل الميزة عندما تنجح AC-01 إلى AC-13، ويجتاز المسار UAT مع مدخل بيانات ومراجعة مصمم، وتصبح نقطة الدخول الجديدة وحيدة، وتُحذف المحررات القديمة من runtime والمستودع.
