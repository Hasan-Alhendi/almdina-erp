# اختبار فرع ALNS

الفرع: `feature/cutting-abc-search-20261105`.

يحتوي الرفع على الدراسة ومشغلاتها، ووحدة Domain اختيارية لتحسين خطة موجودة
مع تثبيت عدد الألواح، واختباراتها وأدلة الطلبين 263 و298. **ALNS غير مربوطة
بزر التحسين في واجهة المدينة بعد**؛ تحديث الموقع إلى هذا الفرع وحده لن يشغّلها
من الواجهة. يمكن اختبار التنفيذ الحالي بالأوامر التالية من جذر المستودع.

## تجهيز بيئة الاختبار

استعمل Python 3.12 وNode.js 20، وبيئة Python منفصلة عن موقع الإنتاج:

```sh
python -m venv .venv
```

فعّل البيئة (`.venv\Scripts\Activate.ps1` في PowerShell أو
`source .venv/bin/activate` في Linux)، ثم:

```sh
python -m pip install '.[test]'
python -m pytest -q almdina_erp/tests/test_alns_research.py almdina_erp/tests/test_fixed_board_layout_search.py --basetemp .pytest_cache/alns-branch-test
```

## اختبار الاستمرار من خطة جيدة

```sh
python scripts/benchmark_fixed_continuation.py --output docs/evidence/alns-fixed-boards/user-continuation-01
```

اختَر اسم إخراج جديدًا لكل تجربة. يشغّل الأمر الطلبين بتكرارين لكل من
استمرار Smart والمنقح الجديد، من نفس اللقطات المشتقة من النظام. يستعمل
CNC Router وريشة 5 مم وTrim صفر ودوران القطع كما في المدخلات المنشورة.
هذه إعدادات المقارنة، وليست إثباتًا لنوع ماكينة المصنع. تصدير DXF الفعلي
وإعادة استيراده Strict جزء من التجربة. النتائج في JSON تتضمن عدد الألواح
والفضلة وطول شبكة مركز الريشة وعدد المقاطع ونجاح التحقق.

```sh
python scripts/summarize_fixed_board_layout.py --cohorts user-continuation-01 --output docs/evidence/alns-fixed-boards/user-summary-01
```

المقارنة المنشورة: 263 ثلاثة ألواح، و298 ثمانية؛ وفي 298 بقيت الفضلة
2.360700 م² مع تحسين الشبكة والمقاطع. لا نتوقع توفير لوح في هذين الطلبين.
الوقت الجداري قد يغيّر اكتشافات البحث؛ راجع كل تشغيل ولا تفترض تطابق الأرقام
بمجرد تطابق الميزانية.

## حدود هذه النسخة

اختبارات الفرع الآلية تحمل اسم `ALNS Research Checks` وتشمل البحث وعقود
الهندسة وPreview والبصمات والمعمارية، وتدقق بصمات الملاحظات المجمدة.
الفحوص الأوسع القائمة تبقى مطلوبة قبل دمج إنتاجي. لا تثبت هذه الفحوص نجاح
Frappe install/migrate أو قبول NC أو اختبار الماكينة الفعلي.

الدراسة [README-ar.md](README-ar.md) توثق نجاح التحسين الدافئ والتراجعين
في تجربة الاستبدال البارد؛ لذلك بقي تشغيل الواجهة الافتراضي كما هو.
لا توجد migrations أو إعدادات مصنع جديدة في هذه الإضافة.

نطاق الرفع هو ملفات ALNS الجديدة وأدلتها مع فحص الفرع ودليل الاختبار.
ملفات الدراسة القديمة وبصماتها تصف لحظة القياس قبل الرفع؛ العبارات التي
تقول إن HEAD بقي `09576ea` أو إن commit لم يُنشأ هي سياق تاريخي لتلك اللحظة،
وليست وصفًا لرأس الفرع بعد النشر. المصدر المجمد هو مرجع بصمات القياس،
وقد تختلف بصمات ملفات العمل بسبب تحويل نهايات الأسطر المعتاد في Git.
تحفظ `.gitattributes` بايتات مجلدي الأدلة دون تحويل نهايات الأسطر.

عقد التغيير: نشر قابل للاختبار للوحدة الاختيارية والبحث فقط؛ تبقى هوية
القطع وKerf وصلاحيات الدوران والمدقق الحالي وملاك الحفظ والبصمات كما هي.
لا تغيير صلاحيات أو تكاليف أو بيانات أو مخطط تخزين أو نصوص واجهة.
لم يُضم تعديل الوثيقة السابق للمستخدم أو أرشيف RAR إلى الرفع.
